### Install ccstatusline for claude statusline

```sh
npm install -g ccstatusline
```

Summary of all the AI tools I use and installation

### Install /grill-me skill

```sh
npx skills@latest add mattpocock/skills --skill=grill-me
```

Above command also asks for other skills in the same source that you might want to install. /grill-with-docs skill can 
be installed with it.

Or Install all the mattpocock skills with

```sh
claude plugins install mattpocock-skills
```

### Alterntively install superpowers plugin that introduces engineering methodologies to the agent

See https://github.com/obra/superpowers for more info and installation steps

superpowers is enabled by default when installed, so when you use mattpocock/skills, some of the instructions shall
collide, so its better to use one of the other.
